# Sidebar Navigation Update

The Admin Portal sidebar now groups the 20 existing destinations into six top-level entries:

- Dashboard
- Students & Staff (Students, Left / Withdrawn, Admit Student, Classes, Teachers, Teacher Portal Accounts)
- Finance (Fee Payment, Fee Pending Slips, Payment History, Finance Details)
- Academic Records (Timetable, Mark Entry, Attendance, Weekly Tests, Term Exams)
- Assignments & Activities (Impositions & Assignments, Late Arrival Work, Hot Seat)
- Data Management (Import Data)

Groups expand as an accordion. The active route's group opens automatically, and route names/targets are unchanged. The same grouped navigation works in the mobile drawer. This update only changes navigation markup, styling, and route-active behavior; no database or business logic changes are included.
